# 저장소 구성과 공개 범위

이 저장소는 곰곰 교육 서비스에서 재사용할 수 있는 코드를 공개하는 출발점입니다. 수학과 한자는 서로 독립적인 구현이며, 언어교육은 아직 계획 단계입니다.

```text
gomgom-open-education/
├─ math/
│  ├─ README.md                 수학 엔진의 역할·파일 지도·실행 방법
│  ├─ examples/                 엔진 호출 예시
│  └─ engine/
│     ├─ build.gradle           Java 라이브러리와 JUnit 의존성
│     └─ src/
│        ├─ main/java/          문제 생성·채점·학습 상태 코드
│        ├─ main/resources/     국가별 일부 교육과정 배정
│        └─ test/java/          기존 엔진 검사
├─ hanja/
│  ├─ README.md                 필기 입력·판정·화면 모듈 안내
│  ├─ writing.js                필기 인식과 WritingPad
│  └─ tests/                    기본 판정 검사
├─ languages/README.md          다국어·TTS 개발 계획
├─ docs/ARCHITECTURE.md         이 문서
├─ settings.gradle             수학 모듈 등록
├─ package.json                한자 검사 실행
└─ LICENSE                     MIT 라이선스
```

## 한 저장소를 사용하는 이유

각 영역은 이미 폴더로 구분되어 있습니다. 수학은 Java/Gradle, 한자는 JavaScript/Node.js로 실행하며 서로를 빌드 의존성으로 요구하지 않습니다. 교육 목적·공개 정책·기여 안내는 함께 관리합니다. 지원 신청에 제출한 주소도 이 저장소입니다.

별도 저장소가 필요해지는 시점은 각 영역이 독립된 배포 패키지, 버전 일정, 관리 팀을 갖게 될 때입니다. 그때 원래 저장소에서 새 주소와 이전 범위를 안내하고 분리할 수 있습니다. 아직 구현하지 않은 언어교육을 별도 제품처럼 만들지는 않습니다.

## 코드 파일과 역할은 다른 단위

수학 코드는 `com.gomgomapps.math.core` 패키지 안에서 여러 파일이 함께 동작합니다. 기능을 설명하기 위해 역할별로 묶지만, 파일을 서로 다른 패키지로 옮기지는 않았습니다. 패키지 내부 접근과 기존 연결을 보존하며 필요한 부분을 먼저 읽을 수 있게 문서를 제공합니다.

한자의 `writing.js`도 필기 판정 함수와 화면 클래스가 한 파일에 있습니다. 현재 공개 범위에서는 데이터와 호출 계약을 먼저 설명합니다. 파일을 물리적으로 나누는 변경은 기존 서비스와 공개 모듈의 동작을 함께 검증할 때 수행해야 합니다.

## 공개한 것과 포함하지 않은 것

| 영역 | 포함 | 포함하지 않음 |
|---|---|---|
| 수학 | 문제 생성, 채점, 학습 상태, 일부 교육과정 배정, 기존 검사 | Android 화면, 스토어 패키지, 결제·계정 기능 |
| 한자 | 필기 판정, 캔버스 입력 모듈, 기본 검사 | 홈페이지 전체, 급수 콘텐츠, 글꼴, 외부 획 데이터, 사용자 기록 |
| 언어교육 | 개발 계획 | TTS 서비스, 음성 인식, 발음 평가, 언어별 콘텐츠 |

따라서 이 저장소를 내려받는 것만으로 현재 운영 중인 앱·홈페이지 전체가 실행되지는 않습니다. 공개된 구성요소를 다른 프로그램에 통합할 수 있습니다. 운영 서비스의 출시 상태와 공개 구성요소의 테스트 결과도 구분합니다.

## 기여 순서

1. 해당 영역의 README와 관련 테스트를 읽습니다.
2. 문제를 재현하는 입력과 기대하는 결과를 설명합니다.
3. 관련 파일만 수정하고 해당 영역 검사를 실행합니다.
4. 실행 환경과 검사 결과를 PR에 기록합니다.

현재 검사 명령은 수학 `gradle :math:engine:test`, 한자 `npm test`입니다. 사용자 개인정보나 서비스 비밀값을 이슈·PR에 첨부하지 않습니다.
