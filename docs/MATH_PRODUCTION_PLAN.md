# 곰곰 수학 제작 계획

갱신: 2026-10-05. 이 문서는 학습 앱의 목표와 제작 방법을 설명합니다. 이 저장소에 공개된 수학 코드는 Android 앱과 독립적인 엔진이며, 앱 전체·운영 서버·결제 설정은 포함하지 않습니다.

## 만들고자 하는 앱

공부하고 싶지만 기초가 어려운 전 세계 학생을 위한 무료 기초 수학 앱을 만듭니다. 국가별 교육과정을 선택하고, 배운 범위의 진단으로 부족한 기초를 찾아 반복 학습하도록 합니다. 국가별 대응은 공식 원문과 실제 학년·단원 범위를 확인하며 확대합니다. 현재 대응표는 일부 기능의 배정이며 세계 교육과정 전체 완료나 공식 인증을 뜻하지 않습니다.

학생이 채울 식의 기본 틀을 제공하고 과정에서 틀린 부분을 표시합니다. 도움을 완료했다고 답을 자동으로 입력하지 않습니다. 같은 정답·보기 위치·표기가 암기 단서가 되지 않도록 문제와 선택지를 다양하게 만듭니다. 단원별 약100문항의 공급과 매일 반복 학습을 함께 확인합니다.

30분·1시간 공부, 개인 숙제와 배운 단원 복습을 지원하는 방향입니다. 반 연결이나 초대 코드를 학습 조건으로 요구하지 않습니다. 휴대폰에서는 답·식을 입력하고 태블릿에서는 연습장도 씁니다. 초등1~3학년의 버튼은 크고 조작은 간단해야 합니다. 모든 학습 기능은 무료이며 광고 제거는 선택입니다.

## 제작 방법

1. 공식 교육과정에서 학년·단원·선행 개념·숫자 범위·단위를 확인합니다.
2. 검증된 공통 계산을 재사용하고, 없는 개념과 풀이 틀만 추가합니다.
3. 각 유형의 계산·풀이 단계·오답 판정·문제 다양성을 독립 검산합니다.
4. 같은 입력 방식의 단원을 묶어 빌드하고 실제 앱의 정상 메뉴에서 확인합니다.
5. 새 입력·저장·공통 화면 변경은 폰·태블릿과 종료 후 복원까지 검증합니다.
6. 코드·제작 계획·검증 요약을 작업 단위로 공개 Git에 남깁니다.

숫자 범위나 국가별 배정만 바뀐 경우에는 해당 범위를 검증하고 변경된 국가·학년의 정상 진입을 확인합니다. 공통 입력·저장 기능이 바뀌면 영향을 받는 기존 단원도 확인합니다. 통과한 검사를 변경 이유 없이 반복하지 않습니다.

## 속도를 높이는 작업

기기 내부 UI Automator에서 정상 버튼·입력 칸·화면 조건을 사용해 대기와 반복적인 호스트 호출을 줄입니다. 같은 실제 화면의 접근성 읽기에서는 기존 방식이 회당 약2.1초, 기기 내부 방식이 첫 읽기531ms와 후속10/7ms였습니다. 같은 화면의 연속 읽기이므로 캐시 영향이 있고 앱 전체 향상 배수를 의미하지 않습니다.

남은 VAT 객관식10문항은 공개 가격·세율·질문으로 독립 계산하고 실제 보기 버튼을 선택해22.711초의 검사 실행 시간에 완료했습니다. 설치·실행기 준비 비용을 포함한 전체 제작 시간 비교는 아직 없습니다. 새 조작과 변경된 화면에서도 실제 입력·저장 결과가 유지되는지 계속 확인합니다.

측정 오차 두 유형에도 같은 방식을 적용해 실제50문항과 대표 폰·태블릿, 초안 복원·최종 저장을 확인했습니다. 백분율 입력 재개49.212초, 객관식 절대25.951초/백분율25.154초는 각 검사 실행 시간입니다. 전체 제작 속도 향상 배수는 아직 산정하지 않습니다. 완료된 풀이 단계와 정상 홈 스크롤을 검사 재개에 반영했고 실제 화면 조건으로 팝업 전환을 기다립니다.

## 남은 작업

- 교육체계·지역·학년·단원별 공식 대응과 누락을 정리하고 확대합니다.
- 공급이 부족한 단원의 문제 다양성을 보완합니다.
- 언어별 숫자·단위·풀이·오류 안내와 실제 입력을 검수합니다.
- 곰 디자인, 연령별 조작, 작은 폰 분수 입력과 태블릿 연습장을 완성합니다.
- 실제30분·1시간 종료, 날짜 경계, 보류·재실행과 실물 기기를 확인합니다.
- 검토 가능한 앱 자료를 출시 담당에게 인수합니다.

전체 완료 날짜와 속도 향상 수치는 교육체계별 남은 작업과 실제 처리량을 측정한 뒤 판단합니다. 최신 공개 작업은 [제작 기록](DEVELOPMENT_LOG.md)에 남깁니다.
