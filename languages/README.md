# 다국어·TTS 학습 계획

이 영역에는 아직 구현된 서비스 코드가 없습니다. 수학·한자와 같은 무료 교육 목적 아래 다음 기능을 개발할 계획입니다.

| 학습 활동 | 필요한 기능 | 현재 상태 |
|---|---|---|
| 발음 듣기 | TTS로 글자·단어·예문 음성 생성 및 재생 | 계획 |
| 따라 말하기 | 녹음·재생 등 말하기 연습 | 계획 |
| 발음 피드백 | 언어별 음성 인식·발음 평가 | 별도 검토 필요 |
| 글자 쓰기 | 입력 화면, 문자별 기준 데이터와 판정 | 언어별 설계 필요 |
| 뜻과 표현 배우기 | 언어별 단어·뜻·예문·복습 콘텐츠 | 계획 |

TTS는 듣기용 음성을 만드는 기능입니다. 발음 평가와 필기 인식을 자동으로 제공하지 않습니다. 한자 필기 모듈도 모든 언어의 문자 인식기로 바로 사용할 수 있는 것은 아닙니다.

## 개발할 때 정할 것

1. 먼저 지원할 언어와 학습자 수준
2. 읽기·발음 체계: 한자의 한국어 독음과 중국어 등의 발음을 구분
3. 재배포 가능한 콘텐츠와 음성 사용 조건
4. 실제 화자나 교사의 발음·예문 검수
5. 비용 관리: 생성 음성의 재사용, 사용량 제한, 지원 종료 후 운영 방법
6. 음성·학습 기록의 보관 여부와 사용자 동의

API 제공자와 모델은 구현 단계에서 현재 기능·품질·가격을 확인하고 선택합니다. OpenAI 지원 신청을 제출한 상태이며 선정·크레딧 지급이나 TTS 사용 승인은 확정되지 않았습니다.

별도 저장소 분리는 독립 실행 서비스와 유지보수 범위가 생긴 뒤 결정합니다. 그전에는 이 문서에서 계획과 구현 완료를 구분합니다.
