Fraction and decimal unit counts
================================

The existing England Year5 decimalUnitCount topic now includes all six directions between tenths, hundredths and thousandths, and four decimal/fraction notation combinations per direction. Counts0..999 give24000 displayed conditions, independently checked with poisoned answer keys. The original four decimal directions and their help draft version are preserved. Existing Year6 digit/value placement is reflected in its regression test.

Visible unit values determine final checks. Answers remain decimal/integer numeric counts. Five optional empty frames relate each visible unit to its decimal value and the shared quantity; no result transfers to the main answer.

Native Android UI, language adapters, QA records and APKs stay private. This selected numeric work does not establish full verbal/contextual/physical representations, fluency or worldwide completion.
