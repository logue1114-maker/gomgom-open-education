# Estimate, then count

Selected Namibia NIED Junior Primary Grade2/3 requirements (printed page7): estimate collections through20/30, group and count to check. A student's estimate is an observation, not a right-or-wrong test. The learner commits their own nonnegative integer estimate; the count input is cleared; the same collection is grouped into fives. Only the subsequently counted value is graded. Estimates, regrouping preference and count drafts survive snapshots and serialization without changing question identity, study duration or error count.

There are80/120 public count-layout conditions (20/30 numeric facts, four layouts), not hundreds of distinct arithmetic facts. Finite exhaustion deliberately repeats the oldest available condition. A nontransferring three-frame recount guide derives its expectations from public geometry. It does not fill the main answer. This does not claim physical-object performance, every country's curriculum or all-device validation.

Tests: `gradle :math:engine:test --tests com.gomgomapps.math.core.GroupedEstimationTest --tests com.gomgomapps.math.core.CollectionGroupingTest --tests com.gomgomapps.math.core.NamibiaPrimaryTest`. Tests cover all visible conditions, independent public counts, pre-count grading guard, inaccurate estimates accepted, stable identity, snapshot/serialization, guide independence and previous-grade diagnosis.
