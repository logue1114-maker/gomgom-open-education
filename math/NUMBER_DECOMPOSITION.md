# Multiple number constructions

Selected Namibia NIED Junior Primary printed page10: Grade2 two-part constructions through99, Grade3 two/three-part constructions through500 and bonds through20. Existing NumberBond gains an optional third part (null in old serialized bonds); existing join9/split9 are reused for Grade3 bonds. numberBuild hides the whole; numberDecompose hides one part. Public givens, part counts and blank positions vary. Indexed composition decoding avoids allocating millions of questions; existing recent signatures prevent early repetition and finite domains deliberately repeat after exhaustion. Zero parts are supported.

Blank nontransferring help uses only visible whole/parts and labeled left/middle/right positions. It never reads the answer key or fills the main answer. This is selected numerical practice, not proof of oral/physical performance, all representations, learning efficacy or a complete national curriculum. Grade1 current recall scope remains under review.

Tests: :math:engine:test with NumberDecompositionTest, NumberConceptTest, NamibiaPrimaryTest. Exhaustive Grade2 conditions, independent visible-part solving, Grade3 random/500 endpoints and two/three representations, help independence and two-part serialization are checked.
