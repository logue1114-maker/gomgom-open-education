# Selected England upper-primary whole-number practice

Source: https://www.gov.uk/government/publications/national-curriculum-in-england-mathematics-programmes-of-study/national-curriculum-in-england-mathematics-programmes-of-study

Eleven explicit placements reuse comparison, three-number ordering and rounding. Year3 compares/orders0–1000; Year4 selects four-digit0–9999 with nearest10/100/1000; Year5 compares/orders/rounds0–1000000 to10/100/1000/10000/100000; Year6 selects0–10000000 and powers of ten through10000000. Year4 is a selected subset of the statutory beyond1000 requirement; these selected tasks do not complete all number strands, reading/writing words, digit-place identification, signed/contextual problems or classroom representations.

Large ordering uses bounded BigInteger ranks over distinct three-number public presentations in both directions. It avoids the former500 cap and cubic enumeration/long overflow. Bounded quotient/remainder values use Android26-compatible int conversion. Existing small-domain finite supplier is preserved. Freshness is based on public conditions;100 fresh conditions per selected placement are tested. This is not a claim of100 different mathematical concepts.

Comparison help uses only public digits, extending positional names through large numbers. Rounding now includes small/zero values only when explicit minGiven is supplied; existing defaults are retained. Large result bounds are converted to plain decimal before exact rational comparison, including rejection above the bound. All help blanks are filled by the student and never transferred to the original answer.

Only educational Java, TSV, tests and this document are public. Private UI, translations, painters, learner records, ads/billing, native QA and APKs are excluded. Android phone behavior is verified separately in the private project.
