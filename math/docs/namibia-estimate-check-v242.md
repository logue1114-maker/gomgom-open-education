# Namibia Grade6 rounding checks

NIED Grade4-7 Mathematics syllabus printed pages40-41 defines the number range through1,000,000 and asks learners to use estimation to check addition/subtraction solutions. The existing rounding-envelope exercise is connected for Grade6 with units10 through100,000. This is a selected plausibility strategy, not exact equality verification or complete curriculum coverage.

maxExactResult guards the public original operands and their exact sum/difference separately from rounded estimates and intentionally incorrect proposed answers. Addition supply directly indexes all permitted operand pairs without an eager pool; default England supply remains unchanged.

Verification includes independent exhaustive small-domain enumeration at every cap, 600 normal Grade6 generated problems without repeats, both verdicts, all five rounding units, public-operand checking with poisoned metadata, boundary rejection, and the official example2515+485. Native app, physical device and student effectiveness evidence are separate.
