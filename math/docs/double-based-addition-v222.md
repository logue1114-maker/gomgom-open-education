# Addition using doubles

Namibia Junior Primary Mathematics, printed page14/PDFpage18, lists doubling and halving as an addition strategy for grades1–3 and gives 30+40=30+30+10 as a grade2 example. This unit implements the doubling addition strategy; it does not claim complete halving, concrete/oral fluency, arbitrary longer sums, or national curriculum coverage.

The learner identifies the smaller and larger public operands, subtracts them to find the difference, doubles the smaller, and adds the difference. Help has five empty inputs and never transfers a main answer. It uses named quantities without requiring letter-variable knowledge.

The sum caps are20/100/500 for grades1/2/3. All ordered nonnegative pairs within each sum cap are indexed:231/5151/125751 conditions. Zero and equal operands are included; unseen conditions are selected before repeating. Checking and rebuilt saved help read only the printed operands, including when stored answers/expressions/guide expectations are poisoned. Existing diagnostic prerequisites and country availability are preserved.

Core/tests/curriculum only; Android screens and learner data are private. Device, broader curriculum, and release completion require separate evidence.
