# Estimate calculation checks

Selected England Year3/4 addition/subtraction plausibility checks. Year3 operands0..999, nearest10/100; Year4 operands0..9999, nearest10/100/1000. Round each public operand half-up, calculate the estimate, compare the absolute difference between the proposed answer and estimate with one rounding unit. Inside the conservative envelope DOES NOT prove exact equality; a wrong exact answer can be inside. Main answers are the student estimate and inside/outside verdict.

Optional17-frame teaching reuses actual rounding decisions for each operand, then student estimate/difference/range selection. Relationship-only blanks; no final-answer transfer. Checker derives values from public prompt; hidden answer/expression poisoning is tested. Recent-aware64 sampled candidates, not an exhaustive finite bank. Both grade links100fresh and boundaries/zero/ties/conservative envelope/direct verdict errors are tested independently.

Only educational core/resources/test/doc are included. App UI/localization/student history/QA/APKs/ads/billing are private. Native/device/Play claims belong to separate private evidence. Broader operations, context/accuracy choice, physical devices, all curricula/languages, learning effectiveness remain unfinished.
