Up-to-four-digit written products
=================================

Selected England Year5 practice supplies integers1..9999 multiplied by one digit0..9 or two digits10..99. Indexed domains contain99990 and899910 genuinely distinct operand conditions. Checking uses public operands and ignores stored answer keys. Existing other-grade multiplication domains remain unchanged.

The original column workspace supports the new kind: four-digit carries, correctly shifted partial products, sum carries, and a six-column result. It marks only incorrect learner-entered cells and returns only the learner-completed final row. Empty place-decomposition help and no help-to-answer transfer are retained.

Four new tests cover every first operand at multiplier boundaries plus every multiplier at place boundaries, poisoned keys/malformed prompts, actual column layout/shift/error cells and own final row, blank help/no transfer, normal fresh100-condition supply per type and Year5-only placement. Existing VerticalWork7 and WrittenSingleProducts3 tests remain local regression evidence. Selected English API26 runtime is separate from full language/tablet/physical/Play or worldwide completion. Android presentation, translations, records, QA and APK are private.
