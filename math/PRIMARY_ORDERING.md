# Primary comparison, ordering and ordinal foundations

Selected Namibia NIED Junior Primary printed page8 requirements are mapped at Grade1. Four skills: numberCompareWords/objectCompareWords compare pairs1–20 verbally, including equality without inequality symbols; numberOrder orders three distinct numbers0–20 ascending or descending; objectOrdinal identifies a visibly marked object1st–10th from an explicit side.

Public-condition domains:400 numeric pairs,400 object pairs,15960 ordered three-number presentations including both directions,110 marked-row conditions. Rearranging three numbers changes the public presentation, not the distinct numeric facts. A finite domain only repeats after fresh conditions are used. Comparison display choices are shuffled with stable stored values; older saved questions retain their choices.

Help is reconstructed from the public diagram: left/right observations then a verbal relationship; each ordered rank as a student blank; dots before the marked object then its position. Help never transfers its expected results to the main answer. No hidden answer markers appear in the supplied geometry.

Reproduction: from the multi-module repository root run `gradle :math:engine:test --tests com.gomgomapps.math.core.PrimaryOrderingTest --tests com.gomgomapps.math.core.NamibiaPrimaryTest`. Independent tests solve every visible condition, check nontransfer after answer-key tampering,100 actual Generator samples per skill,all choice positions,finite ordinal exhaustion,serialization and prior-grade diagnosis boundaries.

This selected written/screen foundation is not the entire Grade1 syllabus or worldwide curriculum coverage. Physical classroom tasks,reading/naming ordinal words and full ordinal sequences remain. Source reference: https://www.nied.edu.na/assets/documents/02Syllabuses/02JuniorPrimary/01Syllabuses/02English/JP_Mathematicssyllabus(English)2024.pdf .
