# Selected decimal measurement stories

England Year5: same-unit ribbon lengths in metres and water amounts in litres, adding two amounts or subtracting a used amount. Operands have one to three decimal places, whole parts0–99; remaining amounts are nonnegative. Existing symbolic decimal addition/subtraction now selects up to3places for Year5 only.

Nine student help steps: choose the relationship, enter both public quantities, choose common precision and multiplier, shift each quantity, calculate the integer total/difference, then restore decimal precision. All numeric fields start blank. Help never transfers an answer to the main problem. The helper reconstructs givens from the visible story, without reading the hidden answer.

Supply uses existing sampled freshness selection;150fresh questions per new type are tested. This is not an exhaustive unique-domain or authored100-question guarantee. Tests cover four contexts, independent arithmetic, zero/equality/mixed precision/carry/borrow, public-only poisoned-answer help, Year5 boundaries and the existing arithmetic helper regression.

This is selected support for EN-Y5-31, not complete curriculum coverage. Wider contexts, strategies, representations, physical devices, oral assessment and all interface languages remain outside this packet. Private UI, learner records, ads/billing and APKs are excluded from this public educational repository.
