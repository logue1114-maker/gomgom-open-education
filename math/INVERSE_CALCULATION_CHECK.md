# Checking proposed addition and subtraction answers

New inverseAdditionCheck/inverseSubtractionCheck ask for both the independently calculated inverse value and a correct/incorrect verdict. Proposed answers include correct values and errors of one, ten or one hundred, in both directions when nonnegative domain permits. Undo addition by subtraction and undo subtraction by addition, then compare with the first public operand. A wrong proposed answer is not silently corrected into the actual sum/difference. Public operands and the proposed answer determine checking and teaching; poisoned hidden answer/expression fields do not determine success.

Main answer requires both numeric inverse value and verdict; two button values are stable internal codes, never numeric learning labels.
