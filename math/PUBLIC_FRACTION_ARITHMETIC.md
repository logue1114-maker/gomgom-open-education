Public fraction arithmetic
==========================

The existing four addition/subtraction IDs are retained. Final checks derive rational values from displayed proper fractions, not saved answer keys or expressions. Numeric equivalents, selected fraction/decimal formats and reduced-answer requirements remain enforced. Error localization uses public fractions and common-denominator forms; ambiguous wrong pairs mark both fields. Zero divided by a positive denominator remains zero.

Tests exhaust 6606 bounded proper operand pairs, poison saved keys, independently compute answers and check 100 fresh questions per Year5 type. The selected Year5 denominator range 2..12 supplies 506/286/1434/756 conditions, 2982 total; unlike denominators share a common factor. Existing optional relationship frames start empty and cannot transfer an answer.

This covers selected computational foundations, not full curricular fluency, representations, countries or languages. Android UI, translations, learner data, APKs and native QA remain private.
