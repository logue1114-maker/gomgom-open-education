# Selected whole-number digit and positional value learning

Source: https://www.gov.uk/government/publications/national-curriculum-in-england-mathematics-programmes-of-study/national-curriculum-in-england-mathematics-programmes-of-study

Year3 three-digit, Year4 four-digit, Year5 up to1000000 and Year6 up to10000000: a new explicit wholePlaceValue task asks for the amount represented by a named digit. Four value placements plus Year6 digit-reading are added; the existing Year5 digit task range is expanded. Explicit minGiven0 includes lower-digit numbers/zero; legacy ranges without the option are unchanged. The new type is excluded from unreviewed Korean/unmapped defaults. These selected numeric tasks do not complete words, oral reading, all representations or contextual number outcomes.

Public whole-number/named-place givens determine the help: student enters the original number, the place unit, the digit and (for value tasks) digit times place unit. No answer-key-derived help, prefilled problem numbers or answer transfer. Only correct previously entered values appear as references. Existing saved digit tasks gain the same public-given help. The digit and its represented value remain distinct. Multiple-choice values come from positional misconceptions with a shuffled correct position, bounded by the selected curriculum; signatures retain public number/place conditions.

Six selected placements generate100 fresh conditions each in tests, with independent visible-number arithmetic, zero/maximum/absent-place boundaries, all four choice positions, references and no transfer. Prior default digit reading and titles are checked narrowly. Private UI/translation/learner records/ads/billing/QA/APKs are excluded.
