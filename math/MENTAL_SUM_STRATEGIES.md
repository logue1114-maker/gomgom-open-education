# Two-digit and three-number mental strategies

Selected England Year2 numeric practice: two operands10..99, nonnegative subtraction and sums up to198; three single-digit operands0..9, sum up to27. This covers selected numeric strategies, not full concrete/pictorial representations or fluency.

The optional guide splits the second two-digit operand into tens and ones, then reuses place-unit grouping/bridging. For three numbers it groups a pair making10 when one exists, otherwise the first pair. This is one optional strategy: the main checker accepts the correct sum regardless of the learner's method. Every guide value is a learner blank; there is no answer transfer. Public operands determine arithmetic and teaching; stored answer keys are not used by the checker.

Generation samples64 candidates and avoids recent signatures when the sampled pool permits it. It is not an exhaustive finite-pool guarantee. Zero second phases and intermediate values below10 reuse whole-number relation teaching.
