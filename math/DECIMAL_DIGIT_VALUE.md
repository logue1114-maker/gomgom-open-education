# Decimal place digits and values

Selected England Year 4 practice asks for both the digit in a given place and the value represented by that digit. The visible numbers are 0.00 through 9.99; positions are ones, tenths and hundredths. This gives 3,000 finite conditions, with no repeated condition before exhaustion and the existing least-recent reuse policy thereafter.

Four student blanks reconstruct the visible decimal, selected digit, place unit and digit × unit. Help does not transfer a result into the main answer fields. Its checks derive from the public prompt rather than answer metadata. Existing digit-only decimal practice remains unchanged. This skill is excluded from unreviewed/default curriculum fallback and is explicitly placed only in England Year 4.

This is a selected component of EN-Y4-24, not evidence of a complete national curriculum or contextual quotient-place identification. Tests cover all 3,000 digit/value pairs, wrong-field index, public-only help restoration, finite fresh supply and legacy generation. Android screens, translations, learner records and release artifacts are not included here.
