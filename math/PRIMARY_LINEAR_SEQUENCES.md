# Selected learner-generated linear sequences

England Year6 EN-Y6-30: build three subsequent terms from a starting number and a signed additive rule, or write the signed additive rule from four known terms. Terms0..100, nonzero difference -12..12:1956 distinct public conditions per type. Increasing and decreasing rules are included. Students supply three independent numeric answers or a signed rule number in the public relation previous number + blank = next number.

The optional five/three teaching blanks derive from public givens and preserve relationship-only labels. Every value is supplied by the learner, with no transfer into final answer fields. Tests independently check every domain and wrong field,100 fresh conditions per type, decreasing input and saved teaching drafts. These selected representations do not claim full free-text rule explanations, wider sequence domains, all national curricula, learning effectiveness, physical device coverage or Play release.

Private UI/translations/history/evidence/APKs/ads/billing are excluded.
