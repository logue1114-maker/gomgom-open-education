# Public math engine update — 2026-10-08

This source update brings the standalone engine and its tests into parity with the current app engine. Android screens, translations implemented in the app layer, billing, advertising, learner records, device evidence and APKs are outside this repository.

## Module connections

`Generator` selects a catalog skill and creates a randomized question. `CurriculumLimits` and `Diagnosis` constrain the selected curriculum and completed learning scope. `HelpPlan` builds the working stages; `WorkChecker` checks student-entered steps, and `Checker` checks the separately submitted answer. `QuestionHistory`, `Review`, `TimedStudy` and snapshot classes preserve learning state.

The recent modules extend this chain:

| Module | Selected foundational work |
| --- | --- |
| `SequenceCalculusRelations` | Arithmetic/geometric sequences, limits, derivatives, integrals |
| `LyceeAlgebraRelations` | Powers, linear inequalities, slopes/intercepts, discriminants and root sums/products |
| `HigherFoundationPractice` | Natural exponential/logarithmic equations, rational-angle trigonometry, binomial probability, conditional probability and two-value distributions |
| `VectorFoundationPractice` | Vector sums, displacement, dot products, norms, parametric lines, circles and normal planes |

These help stages use blank numeric fields and rebuild relations from visible problem conditions. Checked prior student inputs can be referenced by later stages. Completing help does not fill in the main answer. Tests cover deliberately corrupted answer metadata, legacy questions and draft restoration as well as arithmetic.

## Curriculum scope

`main/resources/curricula/global.tsv` includes `fr-men-lycee-general-2026-2027-v1`: selected Seconde/Première/Terminale calculations, with 27/19/27 grade-topic placements (73 total). Seconde and Première use the official 2026 programmes applicable in 2026–2027; Terminale uses the 2019 programme until its replacement takes effect. The existing CP–3e mapping remains available. These are selected foundational calculations, not complete French programmes, proofs, technical streams, or complete worldwide coverage.

Official references: [programme resource index](https://eduscol.education.gouv.fr/5817/programmes-et-ressources-en-mathematiques-voie-gt). The source TSV records programme-specific references; no official PDF is redistributed here.

## Reproduce

With JDK 17 or newer and Gradle 8.14.3, from the repository root:

```sh
gradle :math:engine:test
javac -encoding UTF-8 -cp math/engine/build/classes/java/main -d math/examples/build math/examples/GenerateAndCheck.java
java -cp "math/examples/build;math/engine/build/classes/java/main;math/engine/build/resources/main" GenerateAndCheck
```

The last command uses the Windows classpath separator; use `:` on Linux/macOS. The deterministic example generates a public addition question and checks a deliberately incorrect submission. It demonstrates the library API, not an Android learning session. Unit checks do not prove device usability or Play release readiness.
