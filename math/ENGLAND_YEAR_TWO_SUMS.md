# Selected Year2 integer calculation domains

The existing add100/sub100 generator required both operands10..99 when no explicit whole-digit rule existed. Explicit Year2 rules now allow operands0..99, sums through198 and nonnegative differences through99. Ones and multiples of ten can occur alongside two-digit operands. Existing addThree9 had total capped9; explicit one-digit-per-term generation now permits each0..9 and totals0..27. Existing column and five-blank three-term help remain; answers are never transferred.
